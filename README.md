Write the funniest single-line diagnosis an AI therapist hands its human, 200 characters or less, and let the house judge pick the line that lands hardest.

## Run it

```sh
python3 main.py
```

The program is deterministic and standard-library only: it writes a single
line — a deadpan clinical diagnosis with the laugh landing at the end — to
`/output/entry.txt` (171 characters, one line, UTF-8).
